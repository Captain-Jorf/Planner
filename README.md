# برنامه‌ریز روزانه · Daily Planner (Persian)

اپلیکیشن **برنامه‌ریزی روزانه‌ی فارسی** با **تاریخ شمسی**، طراحی **سه‌بعدی**،
تم رنگی مینیمال پست‌مدرن (نئوپاپ) و خروجی **APK اندروید**.

> ساخته‌شده با Vite + Vanilla JS + Capacitor. تصویرسازی‌ها و آیکون‌ها همگی
> **وکتور (SVG)** هستند و کل داده‌ها به‌صورت **آفلاین** در دستگاه ذخیره می‌شوند.

---

## ✨ ویژگی‌ها
- **۵ بخش** با نوار پایین و دکمه‌ی **خانه در وسط** (شناور و سه‌بعدی):
  1. 📅 **تقویم** — نمای ماه شمسی + ثبت رویداد رنگی برای هر روز.
  2. ✅ **وظایف** — افزودن/تکمیل/حذف کار با سطح اولویت و فیلتر.
  3. 🏠 **خانه** — داشبورد امروز: تاریخ شمسی، حلقه‌های پیشرفت، آمار سریع.
  4. 🔥 **عادت‌ها** — پیگیری هفتگی عادت‌ها با آیکون و رنگ دلخواه و نوار پیشرفت.
  5. ⚙️ **تنظیمات** — نام کاربر، حالت روشن/تیره، یادآوری، پاک‌سازی داده.
- **تاریخ شمسی** کامل با `jalaali-js` و ارقام فارسی.
- **تم دوگانه** روشن/تیره با پالت **۳۲ رنگ** (بین ۲۰ تا ۵۰) و کنتراست مناسب.
- **جلوه‌های سه‌بعدی**: کارت‌های tilt با perspective، سایه‌های لایه‌ای، FAB برجسته.
- **تصویرسازی‌های اختصاصی SVG**: قهرمان صفحه‌ی خانه، حالت خالی، جشن اتمام.
- فونت **وزیرمتن** به‌صورت محلی (بدون نیاز به اینترنت).

## 🎨 تم
پالت در `src/theme.css` تعریف شده: ۷ رنگ خنثی + ۱۳ اکسنت شاد + ۴ رنگ معنایی +
۵ گرادیان. مستند طراحی و **درخت تفکر** در فایل [`PLAN.md`](./PLAN.md).

## 🚀 اجرا در حالت توسعه (پیش‌نمایش وب)
```bash
npm install
npm run dev      # http://localhost:5173
```

## 📦 ساخت فایل APK

### روش ۱ — خودکار با GitHub Actions (توصیه‌شده)
با هر **push** به مخزن، ورک‌فلوی [`.github/workflows/build-apk.yml`](./.github/workflows/build-apk.yml)
یک `daily-planner.apk` می‌سازد:

1. به تب **Actions** مخزن در گیت‌هاب بروید.
2. آخرین اجرای «**ساخت APK اندروید**» را باز کنید.
3. از بخش **Artifacts** فایل `daily-planner-apk` را دانلود کنید.

برای ساخت **Release** با APK ضمیمه، یک تگ نسخه بزنید:
```bash
git tag v1.0.0 && git push origin v1.0.0
```

### روش ۲ — ساخت محلی (نیازمند Android SDK + JDK 17)
```bash
npm run apk
# خروجی: android/app/build/outputs/apk/debug/app-debug.apk
```

## 🧱 ساختار پروژه
```
index.html              نقطه‌ی ورود + صفحه‌ی بارگذاری
src/
  main.js               روتر + نوار پایین + توست
  theme.css             تم و پالت ۳۲ رنگی + جلوه‌های سه‌بعدی
  jalali.js             ابزار تاریخ شمسی
  store.js              وضعیت + ذخیره در localStorage
  icons.js              آیکون‌های SVG
  illustrations.js      تصویرسازی‌های SVG اختصاصی
  nav.js                پل ناوبری بین نماها
  views/                home, tasks, calendar, habits, settings
android/                پروژه‌ی بومی Capacitor (اندروید)
android-resources/      آیکون منبع اپ
```
